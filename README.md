# f2m.php について

## 概要

`f2m.php` は、HTMLフォームから送信された内容を受け取り、確認画面表示、管理者宛メール送信、自動返信メール送信、CSV保存を行うフォームメールPHPである。

プログラムの知識がない利用者でも設置・設定しやすいように、入力フォームは通常のHTMLファイルとして扱う構成である。フォーム側は `form`、`input`、`textarea`、`select` などの通常HTMLタグを記載し、送信先と `F2M_ID` を指定することで利用できる。（実際の配布時には、設置先で Composer を実行しなくても動作するように、`php/vendor/` を含めた状態で受け渡す想定である。）

設定ファイルは、専用の管理画面やプログラム編集を必要としない簡易フォーマットのプレーンテキストである。

旧版は、2000年代に制作した Perl CGI 版を PHP へ移植したものである。本版では、旧版の設定TXT方式とフォームHTML運用を引き継ぎつつ、PHP 8.2+ / Composer 前提の構成へ整理している。処理本体は `php/src/` 配下の名前空間付き関数へ分割し、`f2m.php` は薄い入口として扱う構成である。

## 実行前提

- PHP 8.2 以上である。
- Composer を使用する構成である。
- PHP拡張として `mbstring`、`dom` が必要である。
- 外部ライブラリは `php/vendor/` に配置する。
- `php/` ディレクトリで `composer install` を実行する。

Composer 管理対象の主なライブラリは以下である。

- `phpmailer/phpmailer`
- `smarty/smarty`

## 設置ファイル一覧

設置時に配置する主なファイルとディレクトリは以下である。

```txt
必須:
  f2m.php                         フォーム送信入口
  f2m_conf.txt                    フォーム設定ファイル
  form.html                       入力フォームHTML
  php/composer.json               Composer設定
  php/composer.lock               Composer依存バージョン固定
  php/src/                        フォーム処理本体
  php/templates/                  画面・メール本文テンプレート

環境生成:
  php/vendor/                     Composer依存ライブラリ

実行時書込:
  php/var/cache/                  Smartyコンパイルキャッシュ
  php/var/uploads/                添付ファイル一時保存先
  storage/csv/                    CSV保存先

任意・参考:
  README.md                       この説明ファイル
  _old/                           旧版資産。ローカル参照用であり、Git管理・配布対象外
  docs/                           作成方針等の補足資料
```

`php/vendor/` は `composer install --no-dev` により生成される。Composer を設置先で実行できない場合は、別環境で生成した `php/vendor/` を含めてアップロードする必要がある。

`php/var/cache/`、`php/var/uploads/`、`storage/csv/` は実行時に書込が発生するため、Webサーバー実行ユーザーの書込権限が必要である。

> **重要: CSV保存先の公開禁止**
>
> `storage/csv/` は送信内容の保存先であるため、Webブラウザから直接アクセスできる状態にしてはならない。可能であればWeb公開ディレクトリ外に配置し、公開ディレクトリ内に置く場合はサーバー設定で直接アクセスを拒否する必要がある。

## 設置方法

実際の設置手順は以下である。

1. Web公開ディレクトリへ必須ファイルを配置する。
2. `php/` ディレクトリへ移動し、`composer install --no-dev` を実行する。
3. `php/var/cache/`、`php/var/uploads/`、CSV保存先ディレクトリにWebサーバー実行ユーザーの書込権限を付与する。
4. `f2m_conf.txt` の `F2M_ID`、メール宛先、SMTP設定、テンプレートパス、CSV保存先を設置先に合わせて変更する。
5. フォームHTMLの `action` を `./f2m.php` にし、hidden項目 `F2M_ID` に設定IDを指定する。
6. SMTP送信を利用する場合は、`F2M_MAIL_SENDER`、`F2M_SMTP_HOST`、`F2M_SMTP_PORT`、認証情報を本番環境の値へ変更する。
7. テスト送信を行い、確認画面、管理者宛メール、自動返信メール、CSV保存、完了画面を確認する。

本番環境へ配置する場合、サンプルの Mailpit 用SMTP設定である `127.0.0.1:1025` は使用しない。

## 利用方法

フォームHTMLの送信先に `f2m.php` を指定する。

```html
<form method="post" action="./f2m.php">
  <input type="hidden" name="F2M_ID" value="contact">
</form>
```

`F2M_ID` は `f2m_conf.txt` 内の設定IDである。`f2m.php` は `F2M_ID` をもとに対象設定を選択する。

## 処理フロー

現行の主な処理順は以下である。

1. セッションを開始する。
2. `php/vendor/autoload.php` を読み込む。
3. `f2m_conf.txt` を読み込み、`F2M_ID` 単位の設定配列を構築する。
4. `$_POST`、`$_FILES`、`$_SESSION` からアプリ内リクエスト配列を構築する。
5. `F2M_ID` に対応する設定を取得する。
6. 期限切れの添付一時ファイルを整理する。
7. 添付ファイルを一時保存する。
8. 戻り操作または入力画面復帰時はフォーム画面を表示する。
9. 入力値を検証し、エラーがあればフォーム画面を再表示する。
10. `mode=send` の場合はCSRFトークンを検証し、メール送信、CSV保存、完了画面表示を行う。
11. 送信前の通常POSTでは確認画面を表示する。

## 主な設定項目

`f2m_conf.txt` で利用する主な設定項目は以下である。

| 設定名 | 用途 |
| --- | --- |
| `F2M_ID` | フォーム設定ID |
| `F2M_FROM` | メール送信元 |
| `F2M_TO` | 管理者宛メールの送信先 |
| `F2M_SUBJECT` | 管理者宛メール件名 |
| `F2M_CHK` | 必須チェック対象項目 |
| `F2M_JPNAME` | フォーム項目名と表示名の対応表 |
| `F2M_CHK_EMAIL` | メール形式チェック対象項目 |
| `F2M_CHK_EQ` | 一致チェック対象項目 |
| `F2M_HONEYPOT_FLD` | honeypot用項目 |
| `F2M_MIN_SUBMIT_SECONDS` | 最短送信秒数 |
| `F2M_RESV_TO_FLD` | 自動返信先に使うフォーム項目 |
| `F2M_RESV_SUBJECT` | 自動返信メール件名 |
| `F2M_RESV_TMPL` | 自動返信メールテンプレート |
| `F2M_FORM` | 入力画面テンプレート |
| `F2M_CONFIRM` | 確認画面テンプレート |
| `F2M_FORMERR` | 旧版互換用エラー画面テンプレート。通常の入力エラーでは使用しない。 |
| `F2M_THANKS` | 完了画面テンプレート |
| `F2M_MAIL_TMPL` | 管理者宛メールテンプレート |
| `F2M_CSV` | CSV保存先 |
| `F2M_MAIL_SENDER` | メール送信方式 |
| `F2M_SMTP_HOST` | SMTPホスト |
| `F2M_SMTP_PORT` | SMTPポート |
| `F2M_SMTP_AUTH` | SMTP認証の有効化 |
| `F2M_SMTP_USER` | SMTP認証ユーザー |
| `F2M_SMTP_PASSWORD` | SMTP認証パスワード |
| `F2M_DEBUG` | 詳細エラー表示 |
| `F2M_ATTACH_FLD` | 添付ファイル項目 |
| `F2M_ATTACH_MAX` | 添付ファイル上限サイズ |

## 画面表示

画面表示は `F2m\Render` 名前空間の関数が担当する。Smarty を利用し、テンプレートには `<!--{` と `}-->` を区切り文字として設定している。

入力画面は `F2M_FORM`、確認画面は `F2M_CONFIRM`、完了画面は `F2M_THANKS` で指定する。通常の入力エラーは `F2M_FORM` を再表示し、フォーム値とエラー内容をDOM経由で反映する。`F2M_FORMERR` は旧版互換用であり、通常の入力エラーでは使用しない。

## メール送信

メール送信は PHPMailer を使用する。メール文字コードは UTF-8、エンコードは base64 である。

`F2M_MAIL_SENDER` が `smtp` の場合はSMTP送信を利用する。SMTP認証は `F2M_SMTP_AUTH` が `true`、`yes`、`1` のいずれかの場合に有効となる。

管理者宛メールは `F2M_TO` が設定されている場合に送信する。自動返信メールは `F2M_RESV_TO_FLD` が設定され、対象フォーム項目に値がある場合に送信する。添付ファイルは管理者宛メールに追加する仕様である。

## CSV保存

`F2M_CSV` が設定されている場合、送信内容をCSVへ追記する。CSVの列順は `F2M_JPNAME` の定義順である。CSVファイルが存在しない場合は、初回書込時にヘッダー行を出力する。

CSV値はSJISへ変換して保存する。現状実装では `F2M_CSV_CHARSET` は参照しておらず、SJIS固定である。表計算ソフトでの数式実行を避けるため、`=`、`+`、`-`、`@`、タブ、改行で始まる値は先頭に `'` を付与する。

> **重要:** CSV保存先は送信内容を保存する領域であるため、Webから直接参照できない場所に設定する必要がある。

## 添付ファイル

添付ファイルは `F2M_ATTACH_FLD` で対象項目を指定する。上限サイズは `F2M_ATTACH_MAX` で指定し、未指定時は `3M` 相当で判定する。

確認画面表示前にアップロードファイルを `php/var/uploads/` へ一時保存し、保存情報をセッションへ保持する。保持秒数を超えた一時ファイルは、次回処理時に整理対象となる。現状の保持秒数は 3600 秒である。

## セキュリティとエラー表示

確認画面から本送信する際は、セッションに保持したCSRFトークンとPOST値を照合する。照合に成功したトークンは破棄する。

SPAM対策として、honeypot項目と最短送信秒数を利用する。honeypot項目に値が入っている場合、または受付から本送信までの経過秒数が `F2M_MIN_SUBMIT_SECONDS` 未満の場合は送信不可とする。

例外発生時は汎用エラー画面を表示する。`F2M_DEBUG` が `true`、`yes`、`1`、`on` のいずれかの場合のみ詳細メッセージを表示する。個人情報保護のため、送信内容やエラー内容のログ保存は行わない。

## 使用上の注意

- `f2m_conf.txt` にはメールアドレスやSMTP認証情報を記載するため、不要な公開・共有を避ける必要がある。
- **重要: CSV保存先の公開禁止。** `storage/csv/` は送信内容を保存する領域であるため、Webブラウザから直接アクセスできる状態にしてはならない。可能であればWeb公開ディレクトリ外に配置し、公開ディレクトリ内に置く場合はサーバー設定で直接アクセスを拒否する必要がある。
- `storage/csv/` に個人情報を含む場合は、アクセス制限、バックアップ、保管期間を設置先で管理する必要がある。
- `php/var/uploads/` には添付ファイルの一時データが保存されるため、外部から直接参照できない設定が望ましい。
- 添付ファイルを使用するフォームでは、HTMLフォームに `enctype="multipart/form-data"` を指定する必要がある。
- honeypotを使用する場合は、`F2M_HONEYPOT_FLD` と同名の入力項目をフォームHTMLに配置し、通常利用者には見えない状態にする必要がある。
- 確認画面テンプレートを変更する場合は、`mode=send`、`csrf_token`、`F2M_ID` のhidden項目を削除してはならない。
- 戻るボタンを変更する場合は、`F2M_RET` で始まるname属性を維持する必要がある。
- `F2M_DEBUG` を本番環境で有効にすると詳細エラーが表示されるため、通常は `false` とする。
- 現状実装ではCSV文字コードはSJIS固定であり、`F2M_CSV_CHARSET` の値は反映されない。

## 旧版資産

旧版の `f2m.php` 一式は `_old/` 配下に保管している。`_old/` はAI作業時のローカル参照資料であり、Git管理・配布対象外である。仕様確認が必要な場合は `_old/f2m_utf8.php`、旧テンプレート、旧設定ファイルを参照する。
