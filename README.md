# f2m.php について

## 概要

`f2m.php` は、HTMLフォームから送信された内容を受け取り、管理者宛メール送信・自動返信メール送信・CSV保存・確認画面表示などを行うためのフォームメールPHPです。

既存のフォームHTMLや設定ファイルを利用し、設置先ごとに `f2m_conf.txt` を調整することで、複数の問い合わせフォームに対応できる構成になっています。

## 制作時の背景

ベースとなるPHPはかなり以前に制作されたもので、当時のPHP環境・設置方法・ライブラリ管理を前提に作られています。

そのため、現在の基準から見ると以下の点が古くなっています。

- Composerを前提としていない
- ライブラリ読込が手動管理
- 1ファイルまたは少数ファイルに処理が集中している
- 入力取得、検証、メール送信、CSV保存、画面表示が混在している
- 古いPHP関数・古い記法が残っている可能性がある
- `static class` 的な関数置き場構成にすると、責務分離としては不十分になりやすい

## 今回の目的

今回の目的は、機能を大きく変えることではありません。

既存仕様を維持しながら、PHP 8.2+ / Composer 前提で保守しやすい構成へ整理することを目的とします。

主な目的は以下です。

- 既存フォームの仕様を引き継ぐ
- 設置方法を大きく変えない
- Composerで外部ライブラリを管理する
- 処理責務を分離する
- 今後の修正・調査をしやすくする
- PHPの現行環境で安全に動かせるようにする

## 継承する仕様

以下の仕様は、原則として旧版の挙動を維持します。

- `f2m.php` をフォーム送信先として使う
- `f2m_conf.txt` による設定方式
- 既存HTMLフォームからの送信方式
- 入力チェック仕様
- 確認画面・完了画面の遷移
- 管理者宛メール本文
- 自動返信メール本文
- CSV保存仕様
- 添付ファイル仕様
- 文字コード仕様
- セッション利用仕様
